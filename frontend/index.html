ℹ️ About the CardioAI Platform

Machine Learning Model, Clinical Parameters & Architecture

The CardioAI Platform is a full-stack cardiovascular risk screening solution engineered to assist in early detection and screening of coronary artery disease. It transforms raw clinical laboratory markers into calibrated probabilistic risk scores and interpretable physiological insights.

🧠 Machine Learning Model

  • Algorithm: Optimized Random Forest Classifier with ensemble decision tree voting.
  • Dataset: UCI Heart Disease Database (Cleveland, Hungary, Switzerland, and Long Beach V).
  • Features: 13 validated clinical biomarkers including hemodynamic, metabolic, electrocardiographic, and fluoroscopic metrics.
  • Output: Calibrated risk probability percentage (0% to 100%), classified into Low Risk (≤30%), Moderate Risk (31-50%), and High Risk (>50%).

🛠️ Decoupled Full-Stack Architecture

  • Backend: High-performance Python FastAPI service with asynchronous request routing, automated OpenAPI/Swagger interactive documentation (`/docs`), and CORS security.
  • Authentication: Secure JWT Bearer tokens and PBKDF2-HMAC-SHA256 password hashing (600,000 rounds) protecting patient history.
  • Database: SQLite database with automatic schema migration and indexed query performance.
  • Frontend: Responsive SPA engineered with modern CSS Glassmorphism, animated HTML5 Canvas ECG waveform rendering, dynamic SVG risk gauge, and printable report export.
📚 Interactive Swagger API Documentation is available live at /docs.
